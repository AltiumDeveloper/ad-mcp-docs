# Altium Designer MCP Server documentation

Documentation for the **Altium Designer MCP Server**, the Altium Designer extension that connects AI assistants to
the design you have open through the open [Model Context Protocol](https://modelcontextprotocol.io/): read
schematics, run ERC, read project history, leave Altium 365 comments and build schematic symbols.

The documentation is published in two places, like the other Altium developer products:

| Where | What | Source |
| --- | --- | --- |
| [Altium Developer Center](https://www.altium.com/documentation/altium-developer-center) | The stable introduction and the Quick Start Guide | [`devcenter/`](devcenter/) |
| **<https://docs.developer.altium.com/ad-mcp-docs/>** | The reference: every tool, sample prompts, guides, troubleshooting, with site search and [`llms.txt`](https://docs.developer.altium.com/ad-mcp-docs/llms.txt) | [`content/`](content/), built by [`website/`](website/) |

## Where things are

[AGENTS.md](AGENTS.md) lists the folders, and each folder's README says what it is for. To preview the site, see
[`website/`](website/README.md). To contribute, see [CONTRIBUTING.md](docs/CONTRIBUTING.md); known gaps are in
[OPEN-ISSUES.md](docs/OPEN-ISSUES.md).
