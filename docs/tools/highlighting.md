# Cross-probing and highlighting

`ad_schematic_object_highlight` zooms to and selects components, nets, or pins on a sheet
and dims everything else — the same effect as cross-probing by hand. Ask *"show me that on
the schematic"* and the assistant will drive Altium Designer to it.

If an object exists on several sheets, the assistant will stop and ask you which sheet to
use rather than guessing.
