# Tool reference

You do not have to call these tools by name — the assistant picks them. This section is
here so you can tell what the assistant actually did, and so you can steer it when you want
to (see [Steering which tools get used](../working-with-the-llm.md#steering-which-tools-get-used)).

Tool names are prefixed with `ad_` in Altium Designer. Where a name below ends in `*`, it
stands for a family of closely related tools — one per action — rather than a single one.
Everything except the schematic editing tools is available as shipped; the editing tools in
[Schematic editing (experimental)](./editing.md) appear only if you switch them on.
